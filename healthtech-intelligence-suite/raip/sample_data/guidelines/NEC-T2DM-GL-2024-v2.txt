PURPOSE
This synthetic guideline addresses pharmacologic therapy for adults with type 2 diabetes mellitus.
Version 2.0 supersedes Version 1.0. Where recommendations conflict, Version 2.0 is authoritative.

===PAGE 2===

CLINICAL MANAGEMENT RECOMMENDATIONS
First-line pharmacologic therapy for adults with type 2 diabetes is metformin unless contraindicated.
If metformin is contraindicated or not tolerated, clinicians should use an alternative agent supported
by this guideline rather than reverting to superseded Version 1.0 sulfonylurea-first language.
Lifestyle counseling should accompany pharmacologic therapy.
This guideline does not authorize autonomous diagnosis or autonomous prescribing.

===PAGE 3===

MONITORING
Reassess glycemic control after metformin initiation according to this guideline.
Monitor renal function when metformin is used.
