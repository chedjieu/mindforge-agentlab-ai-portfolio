# Pilot → controlled expansion → enterprise scale

## Phase 1 — Pilot (this repository)

One document type (Clinical Management Recommendations), synthetic corpus, small author group, HITL always on, CI quality gates, fake model for regression.

Measure: grounding, citation, reviewer acceptance, edit rate, latency, cost/section.

## Phase 2 — Controlled expansion

More templates and guideline families, additional tenants, real IdP in staging, pgvector in RDS, Neo4j Aura, Textract OCR worker.

## Phase 3 — Enterprise scale

Multi-region, autoscaling workers, OpenSearch hybrid, model routing, centralized prompt registry, DR drills, enterprise DLP. Still no autonomous diagnosis.
